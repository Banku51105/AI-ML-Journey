# 🏦 Bank Management System

A simple Bank Management System built in Python to practice Object-Oriented Programming (OOP).

## Features

- Create bank accounts
- Deposit, withdraw, and transfer money
- Transaction history
- Savings Account with interest
- Current Account with overdraft
- Account number validation
- Bank class to manage multiple accounts
- Transaction logging using decorators

## OOP Concepts Used

- Classes & Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Composition
- Properties
- Static Methods
- Class Methods
- Decorators
- Dunder Methods (`__str__`)
